# M8B — Pandora Productization & Certification

M8B is implemented through the public installed-wheel composition but is not
accepted. A real reachable Pandora runtime and independent live RESEARCH role
certification are unavailable, so mandatory Journey J13 remains blocked by
`BLK-M8B-PANDORA-RUNTIME-UNAVAILABLE`.

The non-live qualifier proves request export, evidence import, source/provider
lineage validation, unchanged Project bytes/revision/fingerprint, and fail-closed
adoption without independently anchored live certification, including rejection of
caller-self-issued hash receipts. It uses a simulated provider and therefore
cannot satisfy `BLACK_BOX_OUTCOME`, `MIGRATION`, or `PROVIDER_CERTIFICATION`.

Pandora remains RESEARCH-only. Imported evidence is non-canonical, and even a
future independently certified result may only create a semantic proposal; a
separate `project.accept` operation through Project Authority is required for
adoption. The current public composition cannot unlock that proposal path.

Verdict: `BLOCKED_EXTERNAL_PREREQUISITE`.

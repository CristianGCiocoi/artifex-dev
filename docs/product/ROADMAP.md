# ARTIFEX — Roadmap V1 / V2 / V3

## V1 — STANDARDIZE

Goal: turn good development practice into a reproducible, evidence-bound, portable system.

Autonomy model: **human-directed outcomes, ARTIFEX-structured workflow, agent-executed implementation**.

Includes:
- canonical Project Model;
- workflow stages;
- Acceptance Contracts / Evidence Ledger / hierarchical gates;
- filesystem/Git semantic truth;
- human+machine compilation;
- implementation dashboard;
- BEGINNER/GUIDED/EXPERT;
- QUICK/STANDARD/DEEP;
- INTERACTIVE/ASSISTED/AUTONOMOUS;
- Resource Envelope;
- Hermes preferred;
- Codex standalone;
- Claude standalone;
- Manual fallback;
- project/instance lessons;
- candidate improvement overlays;
- lightweight ChangeSets;
- optional DeepSeek and Pandora providers;
- beginner-friendly frozen distribution.

## V2 — AUTOMATE

Goal: make development durable, resumable, orchestrated and cross-project aware.

Likely features:
- SQLite RunStore/index/metrics;
- executable task DAG;
- durable runs and resume points;
- automatic capability-based harness routing;
- parallel worktrees/workers;
- stronger generator/evaluator isolation;
- cross-project portfolio and knowledge;
- historical replay;
- automated improvement validation;
- automatic overlay rebase/update classification;
- methodology import/adoption (Spec Kit/OpenSpec/BMAD);
- optional Maestro execution provider;
- richer Pandora orchestration.

Autonomy model: **policy-directed, agent-orchestrated**.

## V3 — EVOLVE

Goal: make the software-development methodology continuously improve itself within strict privilege and evidence boundaries.

Likely features:
- dynamic workflow composition from approved stage types;
- outcome-directed end-to-end changes;
- autonomous dependency/integration maintenance;
- assumption and ADR revisit monitors;
- methodology candidate variants and evaluation;
- validator effectiveness learning;
- automatic acceptance-contract strengthening;
- cross-project pattern/anti-pattern mining;
- continuous project comprehension/drift detection;
- optional distributed execution;
- optional server/Postgres organization control plane.

Autonomy model: **outcome-directed, self-improving**.

## Storage principle across versions

**Git/files own meaning. Databases own coordination, indexing and telemetry.**

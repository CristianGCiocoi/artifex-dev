# ARTIFEX Windows icon

`artifex-icon-source.png` is the transparent source artwork generated for the
ARTIFEX 2.0.2 Windows shell. `artifex.ico` is derived from that source and
contains 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel entries for native
Windows packaging.

Both assets are distributed under the repository's Apache-2.0 license.
